# Student Grade Manager

A Java console application that manages student records and calculates grades.

## Features
- Add students with marks for multiple subjects
- Automatically calculates average and assigns grade (A/B/C/D/F)
- Saves and loads student data from a text file

## How to Run
1. Clone the repo
2. Open in your IDE
3. Run `Main.java`

## Tech Used
- Java
- File I/O
